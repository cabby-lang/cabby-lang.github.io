Cabby

A small, natively compiled language with a quiet syntax. Every value has an owner, so memory is freed for you, and most mistakes are caught before a program ever runs.

Quiet syntax

No semicolons and no parentheses around conditions. Tabs and braces make the blocks, and both are checked.

Owned, not collected

Values have one owner and are cleaned up when it goes. No garbage collector, no reference counting, and use-after-move is an error before the program runs.

Run it or build it

cabby prog.cby runs a program straight away. cabby -c builds a native program through LLVM, with the same output, typically 10–100 times faster.

Objects

Objects with methods, inheritance and multiple inheritance, made and dropped when you'd expect, with handlers for anything that happens later.

As low as you need

Call the C library directly with extern, or use addresses for memory and hardware addresses.

As high as you want

Libraries for windows, games, 3D, sound and MIDI, files, networks, JSON, databases and the desktop, the same on Linux and the Mac.

Windows in a few lines

A window is an object made from gui.window. Its build method says what's in it, and handlers say what happens when someone clicks or presses Enter. There's no event loop to write.

The manual teaches all of Cabby a chapter at a time, from Hello, Cabby to your first window and beyond, and every example in it is run by Cabby's tests.
